# Ritesh Ranjan — Portfolio

React + Vite + Tailwind CSS v4.

## Run locally
    npm install
    npm run dev      # open the printed http://localhost:5173
    npm run build    # production build into dist/

## Add your content
- Photo: save as `public/images/ritesh.png`
- Screenshots: `public/projects/expense-tracker.png`, `ecommerce.png`, `artisan-market.png`
- Email, repo and demo links: edit `src/config.js` (empty = hidden)

## Deploy
1. Push to GitHub (`git init`, `git add .`, `git commit -m "Portfolio"`, create a repo on github.com, then `git remote add origin <url>` and `git push -u origin main`).
2. On vercel.com choose Add New > Project, import the repo, keep the Vite defaults, click Deploy.
3. Vercel gives you a public `*.vercel.app` URL.
